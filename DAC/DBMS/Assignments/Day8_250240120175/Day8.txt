4. Pass empno as a in parameter to the procedure. If empno is found in the table then,display corrosponding salary out of the procedure. If empno is not found in the table
then, display 0 out of the parameter.

Ans:

mysql> delimiter //
mysql> drop procedure if exists find_emp;
    -> create procedure find_emp(in eno int, out salary decimal(7,2))
    -> begin
    ->  select sal into salary
    ->  from emp
    ->  where empno=eno;
    ->  if salary is NULL
    ->  then
    ->          set salary = 0;

mysql> create function mail(ename varchar(15),job varchar(15)) returns varchar(30)

    ->  declare email varchar(30);

    -> end //

Write a function cal_sal() which calculates maximum salary for the job. Function should return maximum salary to the procedure. Print max sal in the procedure.

Ans:

mysql> delimiter //
mysql> create function cal_max_salary(ejob varchar(20)) returns decimal(7,2)
    -> begin
    ->  declare maximum_salary decimal(7,2);

    -> begin
    -> declare a int;
    -> declare b varchar(15);

    -> declare d int;
    -> declare e date;
    -> declare f decimal(7,2);

8.Pass job as a parameter to procedure and display all employees working for the specified job using cursor.

Ans:-

mysql> delimiter //
mysql> create procedure job_cursor(in ejob varchar(15))
    ->      begin
    ->      declare a int;
    ->      declare b varchar(15);
    ->      declare c varchar(15);
    ->      declare d int;
    ->      declare e date;
    ->      declare f decimal(7,2);

    ->                then
    ->                      leave print;
