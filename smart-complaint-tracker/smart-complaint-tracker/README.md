# Smart Complaint Tracker (Full Project)

Two apps:
- `smart-complaint-tracker-api` — Spring Boot backend
- `smart-complaint-tracker-ui` — React frontend

## Quick Start
1) **Backend**
```bash
cd smart-complaint-tracker-api
mvn spring-boot:run
# Swagger: http://localhost:8080/swagger-ui/index.html
```
2) **Frontend**
```bash
cd ../smart-complaint-tracker-ui
npm i
npm run dev
# open http://localhost:5173
```

You're ready to demo: add complaints, filter/search, update status, see top-urgent and category pie chart.
